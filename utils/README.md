# Utils Folder

## Purpose
This folder contains utility functions and helper modules that provide reusable functionality across the application, such as QR code generation.

## Files

### `qrGenerator.js`
Utility for generating and managing QR codes.

**Purpose:**
Generates QR codes that encode user information for easy sharing and access of user profiles.

**Key Functions:**

#### `generateQRCode(userId, userData)`
Generates a QR code for a user.

**Parameters:**
- `userId` (String) - User's MongoDB ObjectId
- `userData` (Object) - User information to encode
  - `email` (String)
  - `firstName` (String)
  - `lastName` (String)
  - `qrId` (String) - Unique QR identifier

**Returns:**
- Promise resolving to QR code data URL or image

**Example:**
```javascript
const qrCode = await generateQRCode(userId, {
  email: 'user@example.com',
  firstName: 'John',
  lastName: 'Doe',
  qrId: 'qr_abc123xyz'
});
```

#### `validateQRCode(qrCode)`
Validates a QR code format and data.

**Parameters:**
- `qrCode` (String) - QR code data/image to validate

**Returns:**
- Boolean indicating if QR code is valid

#### `encodeUserData(userData)`
Encodes user data into QR code format.

**Parameters:**
- `userData` (Object) - User information

**Returns:**
- String containing encoded user data for QR

#### `decodeQRData(qrData)`
Decodes data from a scanned QR code.

**Parameters:**
- `qrData` (String) - Scanned QR code data

**Returns:**
- Object with decoded user information

**Decoded Fields:**
- `userId` - User's database ID
- `email` - User's email
- `firstName` - User's first name
- `lastName` - User's last name
- `qrId` - Unique QR identifier

## Usage in Controllers

**`Qrcontroller.js` uses qrGenerator:**

```javascript
const { generateQRCode, validateQRCode } = require('../utils/qrGenerator');

// Generate QR code for user
router.post('/generate-qr', protect, async (req, res) => {
  const user = await User.findById(req.userId);
  const qrCode = await generateQRCode(req.userId, {
    email: user.email,
    firstName: user.firstName,
    lastName: user.lastName,
    qrId: user.qrId
  });
  // Store and return QR code
});
```

## QR Code Data Structure

QR codes generated by this utility encode the following information:

```json
{
  "userId": "507f1f77bcf86cd799439011",
  "email": "user@example.com",
  "firstName": "John",
  "lastName": "Doe",
  "qrId": "safepass_abc123xyz",
  "timestamp": "2024-01-15T10:30:00Z"
}
```

## Use Cases

1. **Emergency Access** - First responders scan QR code to access emergency contact info
2. **Profile Sharing** - Users share QR code to let others view their public profile
3. **Medical Access** - Healthcare providers scan to access medical alerts
4. **Access Logging** - Each scan logs who accessed the user's information
5. **Quick Identification** - QR code provides instant user identification

---

## Performance Notes

- QR generation is async to prevent blocking
- Generated QR codes are cached after creation
- Validation checks QR data integrity
- Encoding uses compact JSON format to minimize QR code complexity
