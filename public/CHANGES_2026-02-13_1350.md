# Changes on 2026-02-13 13:50

- Updated reCAPTCHA loading and form logic for development vs production:
  - Removed hard-coded `<script src="https://www.google.com/recaptcha/api.js">` from static HTML pages.
  - Added a `#recaptcha-placeholder` element and dynamic loader in client JS.
  - Client JS (`signup.js`, `login.js`, `forgot-password.js`) now:
    - Loads reCAPTCHA script only when running on production hostnames.
    - Hides placeholder and skips token requirement in development/testing.
    - Guards calls to `grecaptcha.reset()` to avoid runtime errors when grecaptcha is absent.

This allows running locally and in tests without requiring reCAPTCHA, while preserving strict verification in production.
